## 🚀 About the Project

This repository contains the source code for my professional portfolio website, built as a practice project to showcase my frontend development capabilities and specialized e-commerce work. The site features a **Luxury Dark & Champagne Gold** aesthetic, smooth scroll-reveal animations, a responsive mobile navigation system, and a layout optimized for conversions and user experience.

- **Live Preview:** [hassamchuhan.github.io/Hassam-Shopify-Portfolio](https://hassamchuhan.github.io/Hassam-Shopify-Portfolio/)

---

## ✨ Key Features

- **Modern & Responsive Layout:** Fully responsive across desktop, tablet, and mobile viewports with a custom mobile drawer navigation menu.
- **Dynamic Scroll Effects:** Features custom Intersection Observer scroll-reveal animations and sticky header background shifts.
- **Project Showcase:** Highlights selected Shopify and GemPages projects with embedded video walkthroughs and direct live preview links.
- **Interactive UI Components:** Clean semantic markup, structured typography utilizing *DM Sans* and *Playfair Display*, and micro-interactions.

## 🛠️ Tech Stack

- **Markup & Structure:** `HTML5`
- **Styling:** `CSS3` (Flexbox, Grid, CSS Variables, Custom Animations)
- **Interactivity:** `Vanilla JavaScript` (Intersection Observer API, DOM Manipulation)
- **Deployment:** `GitHub Pages`
